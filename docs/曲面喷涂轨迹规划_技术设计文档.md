# 曲面喷涂轨迹规划 — 技术设计文档

## 1. 设计目标

将原有的"简单平面蛇形喷涂"方案替换为基于 STL 网格的**真实车门曲面喷涂轨迹规划**。

### 1.1 已淘汰模块

| 模块 | 文件 | 说明 |
|------|------|------|
| 平面蛇形喷涂执行器 | `door_spray_executor.cpp` | 生成固定 X 坐标的 2D 蛇形路径，不支持曲面 |

### 1.2 新增模块

| 模块 | 文件 | 说明 |
|------|------|------|
| STL 网格加载器 | `stl_mesh_loader.h/cpp` | 解析二进制 STL，存储三角面片和法向量 |
| 曲面喷涂规划器 | `surface_spray_planner.h/cpp` | 基于 STL 网格生成曲面喷涂路径 |
| 曲面喷涂节点 | `curved_surface_spray_node.cpp` | ROS 节点，整合规划与 MoveIt 执行 |

## 2. 算法流程

```
┌─────────────────────────────────────────────────────┐
│                   启动流程                           │
│                                                     │
│  1. 从 ROS 参数加载配置                              │
│  2. 读取车门 STL 文件                                │
│  3. 应用坐标变换（网格偏移 + 车门位姿）                │
│  4. 执行曲面切片轨迹规划                              │
│  5. 发布 RViz 可视化                                 │
│  6. 通过 MoveIt Cartesian Path 逐条带执行             │
└─────────────────────────────────────────────────────┘
```

### 2.1 STL 网格加载

- 支持二进制 STL 格式（80 字节 header + 面片数 + 面片数据）
- 可配置缩放因子（SolidWorks 导出的 mm 单位 STL 使用 0.001）
- 支持刚体变换（旋转 + 平移），用于从模型坐标系变换到世界坐标系

### 2.2 水平切片

对于每个切片高度 `z`：
1. 遍历所有三角面片
2. 对每条边检查是否与 `z` 平面相交
3. 收集交点，取每个三角面片的交线中点
4. 记录对应的面法向量

### 2.3 路径点生成

对于每个切片的采样点列表：
1. 按扫描方向（Y 或 X 轴）排序
2. 计算累积弧长，按 `sample_step` 等距插值
3. 沿法向量偏移 `standoff_distance` 得到 TCP 位置
4. 从法向量构造姿态四元数（X 轴指向表面）

### 2.4 蛇形路径

偶数条带正向扫描，奇数条带反向扫描，减少条带间空行程。

## 3. 坐标系与变换

```
world (固定)
  ├── base_link (机械臂基座)
  │     └── link1 → link2 → ... → link6
  │           └── spray_gun_mount_link
  │                 ├── spray_gun_link
  │                 │     └── spray_tcp_link (喷涂工具中心点)
  │                 └── rgbd_camera_link
  │
  └── door_link (车门)
        ├── 关节位姿: xyz=(0.90, 0, 0.50) rpy=(0, 0, π/2)
        └── 网格偏移: xyz=(-2.035, 0.669, -0.925)
```

STL 网格坐标变换链：
```
STL 原始坐标 (mm)
  → × scale (0.001) → 缩放坐标 (m)
  → + mesh_offset → 居中到 door_link 原点
  → × door_transform → 世界坐标系
```

## 5. 车门位姿修复记录

### 5.1 原始问题

车门 STL 由 SolidWorks 导出，原点位于整车坐标系原点（非网格几何中心），
导致车门在 RViz 中显示位置严重偏离：

- 网格几何中心距 STL 原点约 (2.035, -0.669, 0.925) m
- 原始 URDF 中 `world_to_door_joint` 无旋转 (`rpy="0 0 0"`)，车门未正对机械臂
- Z 方向偏移为 0，车门中心在地面以下

### 5.2 修复方案

1. **door.xacro**：visual/collision `<origin>` 添加偏移 `xyz="-2.035 0.669 -0.925"`
2. **arm_description.xacro**：`world_to_door_joint` 设为 `xyz="0.90 0 0.50" rpy="0 0 1.5708"`
3. **curved_surface_spray_node**：规划器参数中同步设置相同的偏移和位姿
